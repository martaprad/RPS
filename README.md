# RPS
classic game of rock-paper-scissors

Two players each pick their move: rock, paper, or scissors.  Each move beats one other move and loses to one other move:

- Rock beats scissors
- Scissors beats paper
- Paper beats rock

The implementation will be a one player game that has a computer “AI” that randomly picks a move.
